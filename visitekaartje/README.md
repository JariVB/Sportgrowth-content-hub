# Visitekaartje SportGrowth Media (22/11)
- Drukbestand: visitekaartje-drukklaar-91x61mm.pdf (pagina 1 = voorkant, pagina 2 = achterkant).
- Formaat: 85 x 55 mm, met 3 mm afloop rondom (bestand 91 x 61 mm). Tekst minstens 4 mm binnen de snijlijn.
- QR-code: https://sportgrowthmedia.be/links (getest met segno, foutcorrectie H).
- Advies drukker: 350-400 g mat papier, eventueel soft-touch laminaat. Oplage 250 is ruim voor het eerste jaar.
- Aanpassen: kaart.html bewerken, dan `node render.js`.
