# Raster-veilige covers (21/11)
Instagram toont reels in het profielraster als 3:4 (boven en onder ±240 px weg). De titel staat daarom onderaan in de zichtbare zone, in dezelfde stijl als de carrousels (label + titel).
Regel: elke studioreel krijgt voortaan zo'n cover (node cover.js). Achtergrond: rustig beeld van Jari, gezicht vrij.
Aanpassen op een geposte reel: reel openen → ⋯ → Bewerken → Cover bewerken → Uit galerij.
