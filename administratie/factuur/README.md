# Facturen en opdrachtbevestigingen SGM

- Gegevens per document in `data/*.json`, PDF maken met `node maak.js data/<bestand>.json`.
- Nummering facturen: `JJJJ-NNN` (doorlopend per jaar, geen gaten). Opdrachtbevestigingen: `OB-JJJJ-NNN`.
- Op elke factuur: ondernemingsnummer BE 0787.731.753 en "Bijzondere vrijstellingsregeling kleine ondernemingen" (geen btw).
- Nog in te vullen in de sjablonen: IBAN zakelijke rekening, gegevens klant.
